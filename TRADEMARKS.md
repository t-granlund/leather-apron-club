# Trademarks — The Leather Apron Club

The CC BY 4.0 license on this repository governs the *words*. It does not
grant the *marks*. Stated plainly so nobody has to guess:

- **The Leather Apron Club** — the council's name
- **The club stamp** — the rotated stamp device ("the cooperative turn",
  "credentials optional", and kin)
- **The spruce marks** — the TreeMark and grove badges (shared with Spruce
  Grove OS; see that repository's TRADEMARKS.md)

Truthful reference is always fine: say the creed came from the club, link
the page, quote the standing questions with credit — that is the license
doing its work. Using the names or stamps to brand your own event, product,
or council as if it were this one: ask first. Honest hands get a yes and a
thank-you. Rippers get cited — this file, in the takedown.
